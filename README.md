# Dashboard Xbox Game Pass | Microsoft Excel

## Sobre o projeto

Projeto de estudo e portfólio desenvolvido no **Microsoft Excel**, com uma base de dados **inteiramente fictícia** relacionada a assinaturas do Xbox Game Pass.

O objetivo é demonstrar a construção de um **dashboard interativo**, a organização de uma pasta de trabalho e a aplicação de recursos do Excel para apresentar informações de maneira clara e visual. **Os dados e indicadores não representam resultados reais da Microsoft, do Xbox ou de seus serviços.**

## Objetivo

Demonstrar competências práticas em **análise de dados, visualização de informações e Business Intelligence**, com foco na experiência de uso do dashboard e na estruturação dos elementos que o sustentam.

## Ferramentas e recursos

- **Microsoft Excel:** desenvolvimento e organização da solução.
- **Tabelas Dinâmicas:** suporte à consolidação das informações.
- **Gráficos e indicadores visuais:** apresentação das informações no painel.
- **Fórmulas e referências entre abas:** apoio aos cálculos e à atualização dos elementos do dashboard.

## Estrutura da pasta de trabalho

A pasta de trabalho contém quatro abas, mas **somente `Dashboard` ficará visível ao abrir o arquivo**:

| Aba | Visibilidade | Função |
| --- | --- | --- |
| `Dashboard` | Visível | Interface principal de visualização e interação. |
| `Assets` | Oculta | Recursos e referências visuais utilizados no projeto. |
| `Bases` | Oculta | Dados fictícios que alimentam o painel. |
| `Cálculos` | Oculta | Cálculos e consolidações de apoio ao dashboard. |

As abas ocultas integram a estrutura técnica da solução e não precisam ser exibidas para a consulta do painel.

## Como utilizar

1. Baixe o arquivo `Dashboard XBox.xlsx` deste repositório.
2. Abra o arquivo no **Microsoft Excel**.
3. Utilize a aba **Dashboard**, que é a interface visível do projeto.
4. Explore os elementos de visualização e os controles interativos disponíveis no painel.

> **Nota:** para preservar a experiência planejada, recomenda-se abrir o arquivo no aplicativo Microsoft Excel. A compatibilidade de recursos visuais e interativos pode variar em outros visualizadores de planilhas.
